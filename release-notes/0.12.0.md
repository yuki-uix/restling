Restling 0.12.0 — a gentle rhythm of light across the rest screen.

- The whole frosted rest screen now gradually dims by up to 12% and returns to its original brightness every 10 seconds. The default 20-second break contains two cycles; the forest and controls keep their positions.
- During rest, the forest and weather stay still so the whole-screen light is the only ambient movement. Weather animation in the normal forest window remains available.
- The effect is rendered inside Restling's rest windows, including the frosted background and interface. It does not adjust the Mac's display brightness, capture the screen or require a new permission.
- Reduce Motion keeps the rest screen at its original brightness. The effect adds no new rest task or reward, and the timer does not wait for an animation cycle to finish.
- Existing forests, completed rests, event records, backups and reminder settings are preserved. The 20-minute / 20-second default rhythm, Esc, snooze choices and forest-growth rules remain unchanged. Previews still earn no growth.

Universal binary for Apple Silicon and Intel, macOS 13 or later. Interface language: Simplified Chinese.

This preview is ad-hoc signed and has not been notarized by Apple. On first launch, macOS may require approval in System Settings → Privacy & Security → Open Anyway. Developer ID signing and notarization remain deferred.
