Restling's first public preview.

- A macOS menu bar companion for a gentle 20-minute / 20-second eye-rest rhythm.
- Grow a personal pixel forest by completing breaks, with tree species and changing local weather.
- Native frosted full-screen reminders, local profiles, and no punishment for skipping a break.
- New Restling name and sprout icon; existing local forest progress is preserved.
- In-app update notices connected to GitHub Releases, with a copyable Homebrew upgrade command.
- Universal binary for Apple Silicon and Intel, macOS 13 or later. Interface language: Simplified Chinese.

This preview is ad-hoc signed and has not been notarized by Apple. On first launch, macOS may require approval in System Settings → Privacy & Security → Open Anyway.
