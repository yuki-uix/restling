Restling 0.10.0 — keep a copy of your forest.

- New real rest attempts are stored locally with a stable ID, forest ID, terminal time, configured duration and completed/skipped result. Retries and restored timer snapshots do not create duplicate records or growth.
- Existing forests keep their cumulative progress, trees and unlocks. Detailed recording starts after upgrading; earlier individual rests and daily dates are not invented. A completed result means the timer finished, not that looking into the distance was verified.
- Open “数据与备份” from the main window or menu bar to see local totals and export a versioned JSON backup of all forests, portable settings and events.
- Restore validates files and previews the current and incoming counts before replacing all local data. It does not merge or add totals. Files over 20 MiB and invalid or unsupported backups are rejected before applying changes.
- Each confirmed restore first saves and checks a local safety copy. “恢复上次恢复前的数据…” can review and restore the latest copy after relaunch; this also preserves the current dataset in a new safety file. Earlier safety copies are retained.
- Restoring starts a fresh use interval with reminders paused. Running timers, temporary snooze/DND deadlines, macOS login items and update caches are not imported.
- An unreadable local archive can be repaired from a valid backup after its exact raw bytes and portable settings are saved in a local safety copy. Returning to that copy explicitly returns to the previous unreadable state; a valid backup can repair it again. Unknown counts are shown as unavailable, and raw export is kept separate from a complete backup.

This release completes the local data foundation and backup scope in Epic #18 (#7 and #8). Calendar/weekly-report UI, accounts and cloud sync are outside this release. The separate forest ecology work in #9 and #10 remains planned; the broader v0.10 milestone is not complete.

The default rhythm remains 20 minutes / 20 seconds. Universal binary for Apple Silicon and Intel, macOS 13 or later. Interface language: Simplified Chinese.

This preview is ad-hoc signed and has not been notarized by Apple. On first launch, macOS may require approval in System Settings → Privacy & Security → Open Anyway. Developer ID signing and notarization remain deferred.
